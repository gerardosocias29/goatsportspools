# CLAUDE.md - Project Guidelines

## UI/UX Reference
When building or modifying UI components, always refer to `free-react-tailwind-admin-dashboard-main/` as the primary UI/UX reference. Use its components, layouts, and styling patterns as the design system for this project.

## Project Structure
- **Frontend**: `src/` (React app)
  - `src/v2/` - V2 pages and components
  - `src/app/` - V1 pages, contexts, and shared utilities
- **Backend**: `goatsportspools-backend/` (Laravel API)
- **UI Reference**: `free-react-tailwind-admin-dashboard-main/` (Tailwind admin dashboard template)
